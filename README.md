# SkyCast ☁️
### 天気予報 Web アプリケーション

SkyCast は、日本国内の都市の現在の天気や今後の天気予報を確認できる Web アプリケーションです。

Next.js、React、TypeScript、Tailwind CSS を使用して開発し、Open-Meteo API から天気データを取得しています。

天気の情報を分かりやすく表示するため、3D 天気アイコン、グラデーション背景、カード型レイアウトを採用しています。

---

## 3. 主な機能

### 3.1 都市の検索・選択

日本国内の20都市から、天気を確認したい都市を選択できます。

対応都市：

東京、大阪、札幌、那覇、横浜、名古屋、京都、神戸、福岡、熊本、広島、仙台、新潟、金沢、長野、静岡、鹿児島、長崎、山形、米沢

都市名による検索機能も備えています。

選択した都市の緯度と経度を使用して、Open-Meteo API から天気データを取得します。

### 3.2 現在の天気

選択した都市について、以下の情報を表示します。

- 都市名
- 現在の気温
- 天気の状態
- 天気に対応した3Dアイコン
- 風速

### 3.3 天気の詳細情報

以下の気象情報をカード形式で表示します。

- 湿度（%）
- 体感温度（℃）
- 風速（km/h）
- UV指数

### 3.4 24時間の天気予報

時間ごとの天気予報を横スクロール形式で表示します。

表示内容：

- 時刻
- 天気アイコン
- 予想気温
- 降水確率

### 3.5 7日間の天気予報

今後7日間の天気予報を表示します。

表示内容：

- 日付と曜日
- 天気アイコン
- 天気の状態
- 最高気温
- 最低気温
- 降水確率

### 3.6 天気に応じた背景デザイン

現在の天気や昼夜の情報を利用して、天気カードの背景色を切り替える仕組みを実装しています。

### 3.7 レスポンシブデザイン

パソコン、タブレット、スマートフォンなど、異なる画面サイズに対応したレイアウトを採用しています。

### 3.8 ローディング・エラー処理

天気データの取得中は、ローディングメッセージを表示します。

API からデータを取得できない場合は、エラーメッセージを表示します。

また、都市の切り替え時には AbortController を使用して、不要になった通信を中止します。

## 4. APIについて

本アプリケーションでは、Open-Meteo Forecast API を使用しています。

API：

https://api.open-meteo.com/v1/forecast

公式サイト：

https://open-meteo.com/

都市ごとの緯度・経度を指定して、気温、天気コード、風速、降水確率などの情報を取得します。

取得した天気コードをアプリケーション内で判定し、日本語の天気表示とアイコンに変換しています。

## 6. インストールと起動方法

### 6.1 必要な環境

- Node.js
- npm
- Visual Studio Code などのエディタ
- インターネット接続

### 6.2 プロジェクトの準備

ターミナルでプロジェクトのディレクトリに移動します。

```bash
cd weather-app
```

依存パッケージをインストールします。

```bash
npm install
```

### 6.3 開発サーバーの起動

```bash
npm run dev
```

ブラウザで以下の URL にアクセスします。

http://localhost:3000

### 6.4 開発サーバーの停止

ターミナルで `Ctrl + C` を押します。

## 7. 動作確認

以下のコマンドを使用して、コードとビルドを確認します。
